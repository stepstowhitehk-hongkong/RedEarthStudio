# Red Earth Studio

A single-page studio website built with plain HTML and CSS.

## Preview locally

Run `python3 -m http.server 8000 --directory dist` from the repository root, then open <http://localhost:8000>.

The `dist/` directory is the source copy. `docs/` is a matching GitHub Pages copy. To publish it, open **Settings → Pages**, choose **Deploy from a branch**, then select branch `main` and folder `/docs`.
